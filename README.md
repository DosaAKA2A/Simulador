# Simulador del bot de WhatsApp de Corlima

Prueba del bot de recepción en el navegador: no envía nada a WhatsApp ni usa claves.
Los pedidos son de prueba (PRUEBAPAG, PRUEBAPRE, PRUEBAENV, PRUEBACAN) y los productos
salen de una copia del catálogo de corlima.pe (`catalogo.json`).

Se genera desde el repo del bot con `node scripts/build-simulador.mjs ../Simulador`.
